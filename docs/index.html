methodology

How the numbers are made

Suite

GPQA diamond — 198 expert-written, multiple-choice science questions. The dataset is gated; question text never leaves the rig and is never published here. Dev runs use a fixed 20-question subset (seed 42).

Anti-leak fairness

Answer choices are re-shuffled per question with a recorded seed, so a model can't win by positional bias. Temperature 0 everywhere. The exact shuffle is stored in every run's config.

Agents

single-agent answers directly. mixture-of-agents runs six domain-specialist proposers, then one aggregator synthesizes. refine passes the answer through all six models in sequence, each critiquing the last. Graph-of-Agents variants plug in through the same interface.

Cost model

Wall-clock seconds × an assumed $0.50/GPU-hour (4090-class rental), configurable per run. Token counts are reported raw alongside, so you can re-price with any rate you like.

Honesty labels

paper rows are numbers reported by the GoA authors — reference targets, not local measurements. measured rows were executed on the 24 GB rig and link to full run logs.

Reproduce it

The runner, agents and compiler live in benchmark/. Point it at any OpenAI-compatible endpoint, or at the six vLLM servers from the GoA replication scaffold — the pool serves models one at a time and swaps them between agent steps automatically.
