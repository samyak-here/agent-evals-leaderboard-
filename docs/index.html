methodology

How the numbers are made

01

Suite

GPQA diamond — 198 expert-written multiple-choice science questions. The dataset is gated; question text never leaves the rig and is never published here. Dev runs use a fixed 20-question subset.

02

Anti-leak fairness

Answer choices are re-shuffled per question with a recorded seed, so no model wins on positional bias. Temperature 0 everywhere. The exact shuffle ships in every run config.

03

Agents

single-agent answers directly. mixture-of-agents runs six domain-specialist proposers, then one aggregator synthesizes. refine passes the answer through all six models in sequence. Graph-of-Agents variants plug into the same interface.

04

Cost model

Wall-clock seconds × an assumed $0.50/GPU-hour (4090-class rental), configurable per run. Raw token counts are reported alongside, so any rate can be re-applied.

05

Honesty labels

paper rows are author-reported reference targets, not local measurements. measured rows executed on the 24 GB rig and link to full run logs.

06

Reproduce it

The runner, agents and compiler live in benchmark/. Point it at any OpenAI-compatible endpoint — or at the six vLLM servers from the GoA scaffold, which the pool serves one at a time, swapping between agent steps automatically.
