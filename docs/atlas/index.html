how it works

No server. No tracking.
Just vectors.

Every repo's README is chunked and embedded with all-MiniLM-L6-v2 into 384-dimensional vectors, precomputed once and shipped as a static file. Your query is embedded in this tab with the same model running in WebAssembly — then ranked by cosine similarity. Nothing you type ever leaves your machine.
